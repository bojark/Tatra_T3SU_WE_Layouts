# Tatra T3SU WE Layouts

Custom Write Everywhere layouts for my Tatra T3SU tram in Cities: Skylines II.

![Tatra T3SU front and side displays](https://github.com/bojark/Tatra_T3SU_WE_Layouts/blob/main/20260827174448_1.jpg?raw=true) ![Tatra T3SU Write Everywhere layout](https://github.com/bojark/Tatra_T3SU_WE_Layouts/blob/main/20260827174422_1.jpg?raw=true)

## Installation

1. Subscribe to [Write Everywhere](https://mods.paradoxplaza.com/mods/92908/) and all its required dependencies.

2. Subscribe to the Tatra T3SU asset.

3. Download the `.wedefault.xml` files from this repository.

4. Place the downloaded files in the following folder:

   ```text
   %USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\ModsData\.Klyte45Mods\WriteEverywhere\layouts
   ```

   If you do not know how to access the `AppData` folder, you can easily find instructions online.

5. Launch the game. The layouts should be applied automatically. If they are not, try refreshing the layouts through the Write Everywhere settings in the in-game menu.

6. Enjoy, and feel free to say thanks!
